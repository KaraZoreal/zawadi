HOW TO USE - 5 MINUTE SETUP

1. SET ENVIRONMENT VARIABLES
   Client/.env:
   VITE_SUPABASE_URL=your_project_url
   VITE_SUPABASE_ANON_KEY=your_anon_key

   API/.env:
   SUPABASE_URL=your_project_url
   SUPABASE_SERVICE_ROLE_KEY=your_service_key

2. CREATE SUPABASE DATABASE
   → Supabase SQL Editor
   → Paste entire supabase-setup.sql
   → Click Run
   → Wait for success message

3. CREATE ADMIN USER
   → Run SQL from SUPABASE_SETUP_GUIDE.md section 4
   → Get UUID from auth users table
   → Insert into user_profiles and admin_users

4. START DEVELOPMENT
   Terminal 1: cd client && npm run dev
   Terminal 2: cd api && npm run dev

5. DEPLOY TO VERCEL
   Frontend: vercel (from client/)
   Backend: vercel (from api/)
   Set env vars in Vercel dashboard

WHAT HAPPENS WHEN USERS SIGN UP
================================================================================

1. User enters: email, password, name, country
2. Country → Auto-detects language group
3. Creates Supabase auth user
4. Inserts user_profile record
5. TRIGGER FIRES ⭐
6. Database scores all active scholarships
7. Stores 8-dimension scores
8. Returns top 20 matches
9. User sees "Smart Scholarship Matching"
10. User can click scholarship for detailed match breakdown

================================================================================
8-DIMENSION RECOMMENDATION ENGINE
================================================================================

Weighted scoring across 8 factors:

1. Education Match     (15%) - Does scholarship match user's level?
2. Country Match       (20%) - Is user in scholarship's target countries?
3. Field Match         (15%) - Does field of study align?
4. Level Match         (10%) - Is user at correct academic level?
5. Language Match      (15%) - Can user handle scholarship's language?
6. GPA Match           (10%) - Does GPA meet requirements?
7. Coverage Match      (8%)  - Is scholarship amount suitable?
8. Timing Match        (7%)  - Is deadline far enough away?

RESULT: Overall score (0-1.0) = 0-100%

ADMIN LOGIN - FIXED ISSUE
================================================================================

PROBLEM (Previous Version)

→ API returned "Request Failed"

ROOT CAUSE

SOLUTION (Current Version)
