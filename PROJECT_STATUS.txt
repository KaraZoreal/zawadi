├── Country Match (20%) - Exact or target country

├── GPA Match (10%) - Academic performance
├── Coverage Match (8%) - Full/Partial/Selective
├── Level Match (10%) - Study level
└── Timing Match (7%) - Not past deadline

Auto-Generated On:
- New user signup
- Profile updates (key fields)
- Scholarship additions
- Regular recalculation (optional)

Stored In: recommendation_scores table
Retrieved By: get_top_recommendations() function
